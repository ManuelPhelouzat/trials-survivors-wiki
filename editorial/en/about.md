# About

This independent community wiki documents Trials Survivors. Starting values and relationships come from serialized Steam build {{BUILD}} data. Actual values can depend on modifiers, targets, and runtime context. The wiki records formulas without simulating damage.

## Contributing

Open a pull request in this wiki repository. To expand a skill, add a note under `editorial/en/notes/` using the corresponding skill filename. The build will add a link from the skill page. Include the build, sources, and limitations. Propose corrections to generated data in GameDataExtractor.
