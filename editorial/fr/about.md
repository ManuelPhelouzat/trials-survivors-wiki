# À propos

Wiki communautaire indépendant consacré à Trials Survivors. Les valeurs de départ et les relations proviennent des données sérialisées du build Steam {{BUILD}}. Les valeurs effectives en jeu dépendent notamment des modificateurs, des cibles et du contexte. Les expressions sont documentées sans simulation de dégâts.

## Contribuer

Proposez une pull request dans le dépôt de ce wiki. Pour compléter une compétence, ajoutez une note sous `editorial/fr/notes/` avec le même nom de fichier que la compétence. La construction ajoutera un lien depuis sa page. Indiquez le build, les sources et les limites des observations. Les corrections de données générées se proposent dans GameDataExtractor.
